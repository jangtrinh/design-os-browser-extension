dom.openOrClosedShadowRoot()
Gets the open shadow root or the closed shadow root hosted by the specified element. If the shadow root isn't attached to the element, it will return null.
Note:
In Firefox, the equivalent property is element.openOrClosedShadowRoot. This read-only property represents the shadow root hosted by the element, regardless of whether its mode is open or closed.
Use Element.attachShadow() to add a shadow root to an element.

Syntax
js
let shadowRoot = browser.dom.openOrClosedShadowRoot(

)
Parameters
element
HTMLElement. The host element.
Return value
A ShadowRoot object instance, regardless of whether its
mode is set to open or
closed, or null if no shadow root is present.

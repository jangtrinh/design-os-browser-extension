## MCP `stdio` Tools (`node cli/dist/browser-agent.js mcp`)

- `browser_capabilities` — Inspect attached extension browser capability tier and active adapters.
- `browser_observe` — Capture compact accessible DOM snapshot and current (pageId, epoch, leaseId) fence.
- `browser_act` — Fenced click_ref or fill_ref on an allowlisted host. Read-only clicks (navigation, show more, pagination) run directly; writes (send, like, comment, connect, typing) return BLOCKED_POLICY with an approvalId until a human allows that exact act in the extension popup.
- `linkedin_status` — Check LinkedIn session status, Human Gate state, pacing counters, and Copilot queue depth.
- `linkedin_search` — Extract structured LinkedIn search results (people, posts, jobs, companies) from the accessibility tree.
- `linkedin_get_profile` — Read a LinkedIn person profile into normalized JSON and cache into local SQLite.
- `linkedin_get_post` — Read a LinkedIn post/activity into normalized JSON and cache into local SQLite.
- `linkedin_get_company` — Read a LinkedIn company page into normalized JSON and cache into local SQLite.
- `linkedin_get_job` — Read a LinkedIn job posting into normalized JSON and cache into local SQLite.
- `linkedin_read_analytics` — Read followers, connections, profile viewers, post impressions, search appearances and per-post impressions/engagements from a profile, creator analytics, profile-views or post page.
- `linkedin_read_comments` — Read comments already rendered on a post (never clicks to expand), or on the newest post of a profile with latest=true and publicId.
- `linkedin_list_inbox` — List LinkedIn messaging inbox threads or read a single thread when threadId is given.
- `linkedin_draft_write` — Stage a Copilot draft (message, comment, post, connect_note) into human approval queue and optionally prefill visible composer without clicking Send.
- `linkedin_query_cache` — Run fast read-only SELECT / WITH SQL queries over locally cached LinkedIn profiles, posts, companies, jobs, threads, searches, and queue items.
- `reader_list` — List available read-only site adapters, views, required fields, and default max_age_s without loading a page.
- `reader_read` — Read a site view into a dos.reader.v1 envelope using cache-first freshness, shared per-site pacing, Account Guard, and third-party redaction.
- `reader_query_cache` — Query shared reader_results/reader_latest/reader_series cache via SELECT/WITH SQL or structured site/view/since filter.
- `reader_check` — Run a read-only comparison check (duplicate_text, profile_links, link_status, subreddit_rules). Never acts or mutates.
- `pacing_status` — Inspect per-site reader pacing budgets, remaining hourly/daily loads, and stall pause state.
- `guard_status` — Inspect per-site Account Guard state (CLEAR or PAUSED with reason, since, evidence_id). Clearing is human-only in popup.
- `evidence_get` — Retrieve verified file paths and SHA-256 manifest for a reader evidence_id.
- `audit_query` — Query hash-chained read-only reader audit rows by since, site, or caller.

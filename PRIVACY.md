# Privacy Policy (`design-os-browser-extension`)

`design-os-browser-extension` is a local-first, source-available engineering workspace and `UKMC.v2` knowledge base in the **DESIGN:OS** ecosystem.

## Zero Telemetry Commitment

- **No telemetry:** Repository scripts (`scripts/self_check.py`, `scripts/verify_bridge_primitives.py`) make zero network calls and emit zero analytics.
- **Local evidence captures:** External documentation cited in `knowledge/agent-browser-extensions/` was frozen into hashed plain-text snapshots under `_evidence/` and verified against live source URLs via `knowledge_builder.cli run review`.
- **Auditable source:** All files are plain text under the [PolyForm Shield License 1.0.0](LICENSE).

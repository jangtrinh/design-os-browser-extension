## Commands

- install: `npm install`
- typecheck: `npm run typecheck`
- build: `npm run build`
- test: `npm test`
- e2e: `npm run test:e2e`
- self-check: `python3 scripts/self_check.py`
- verify-pack: `PYTHONPATH="${KNOWLEDGE_BUILDER_REPO:-../design-os-knowledge-builder}/src" python3 -m knowledge_builder.cli pack check --root knowledge/agent-browser-extensions`
- validate-pack: `python3 "${KNOWLEDGE_BUILDER_REPO:-../design-os-knowledge-builder}/skills/es-knowledge-forge/validate.py" --root knowledge/agent-browser-extensions`

## Localhost Contract

- `localhost_port: 4347` (`127.0.0.1:4347`) — loopback WebSocket broker (`browser-agent daemon`) and deterministic E2E harness. Never use random or fallback ports.

## Binding Rules

- Require TypeScript `>= 7.0.2` (`tsc --version` checked in CI/self-check).
- Follow `AGENTS.md` and `CONTEXT.md` canonical terms before authoring extension or CLI bridge code.
- Never hand-edit `knowledge/agent-browser-extensions/claims/`, `sources/`, `captures.jsonl`, or `index.json`.
- Enforce non-bypass human handoff (`BLOCKED_CHALLENGE`, `BLOCKED_AUTH`, `BLOCKED_PAYMENT`, `BLOCKED_POLICY`) on CAPTCHAs, 2FA, paywalls, and unapproved outbound writes.
- Never request or attach `chrome.debugger` in the LinkedIn adapter or shipping extension manifests.
